# React AWS Serverless Full-Stack App

A full-stack serverless web application built using **React + AWS services**.

This project demonstrates how to build a scalable cloud-native web app using modern serverless architecture.


## Tech Stack

**Frontend**

* React.js
* Bootstrap UI
* AWS SDK integration

**Backend (Serverless)**

* AWS Lambda
* API Gateway

**Authentication**

* AWS Cognito

**Database**

* DynamoDB

**Hosting**

* S3 + CloudFront (planned deployment)


## Features

* User authentication (login/signup with Cognito)
* Form submission workflow
* Dashboard for viewing data
* Serverless API integration
* Cloud-native architecture


## Project Structure

frontend → React application
backend → Lambda functions (to be added)
terraform → Infrastructure setup (planned)


## Purpose of this project

This project was built to demonstrate:

* Serverless architecture design
* AWS cloud integration
* Full-stack development skills
* Scalable web application structure


## Future Improvements

* Add monitoring with CloudWatch
